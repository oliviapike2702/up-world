# brand — visual identity

The described brand system, so agents can brief and judge visual work without opening Drive.

- ✓ `brand-guidelines.md` — colours (hex), Figtree type rules, logo, illustration and
  photography style, brand house. Harvested from the Brand Guide V1 PDF.
- ✓ `asset-map.md` — pointers to the real files: Drive folders (logos, graphics, photos),
  the brand book PDFs, the Canva brand kit.
- ✓ `design references/` — real screenshots of past graphics (Up Fest, Up Club, Up Talk,
  the Accelerator), used to read the actual visual pattern rather than guess it. Note:
  the Brand Hackers file in here is a sister brand's own colours/type, not ours — only
  borrow layout ideas from it, never its palette.

Voice lives in `../tov/`, audience research in `../audience/`.
