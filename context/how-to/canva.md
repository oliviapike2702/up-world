# How we make graphics in Canva

Documented from Liv, July 2026. Visual brand rules (colours, fonts, logo, photo treatment)
live in `../brand/brand-guidelines.md` — this file is just the process.

## Who
Liv makes most graphics; Nzola, Abbie and freelancers also make them. Everyone ships their
own work — there is no sign-off step.

## The Canva account
The Canva team is shared with Brand Hackers and Up Talent, so most designs in there are NOT
Up World's. When hunting for something to reuse, check it is actually an Up World design and
recent (old branding is still floating around). The **Up World brand kit** is set up in
Canva with the brand colours and fonts.

## Making a new graphic
1. Find a recent Up World design of the same type and **duplicate it**, then edit. Starting
   from blank is the exception, not the rule.
2. Take the dimensions from the design you duplicated — sizes vary by use and there are no
   fixed defaults, so match the channel and the source design.
3. Apply the brand rules from `../brand/brand-guidelines.md` (80/20 pink/navy, Figtree,
   wonky circle for photos with white keyline).

## Export and where files end up
- Export as **JPG** usually; **PDF** sometimes (print-ish things like postcards, name tags).
- No single home for finished files — it depends on use:
  - one-off use → download and use directly
  - email graphics → uploaded into Mailchimp
  - keepers/reusable → Drive `Assets/Graphics` (see `../brand/asset-map.md`)
