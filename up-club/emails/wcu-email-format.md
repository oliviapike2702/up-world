# WCU ("What's Coming Up") email — format & benchmarks

Harvested 8 July 2026 from the Liv Handover doc (Jan 2026). The Monday members-only email. Written by Nzola today (in Jan 2026 it was Liv/Abbie); sent via Mailchimp.

## Key details

- **When:** every Monday, usually around 4pm (not strict).
- **Who:** members only — Mailchimp segment "seductive" (paying members), excluding the bounce segment.
- **What:** the key membership things to know this week. It used to be long and nobody read it, so it was deliberately stripped back — keep it short.

## Usual metrics (benchmarks)

- 50% open rate
- 5% CTR
- 0.1% unsub rate

Reported weekly in the Up Club Reporting sheet.

## Section-by-section format

1. **Top header** — can be generic for the whole month (e.g. "February updates") and stay the same all month. Header graphics live in the email banners Canva deck.
2. **Intro paragraph** — the one flexible slot: doors opening, last week's Up Talk recording, an Up Talk or IRL event coming up.
3. **Huddle Ups** — update every Monday so it shows the two happening that week.
4. **Events** — delete Up Talks after they've happened; keep everything in date order (line-up source: the Up Club Luma calendar).
5. **Jobs** — pull 3 live, up-to-date roles from the Up Talent job board (usually the top 3).
6. **Community discussion** — go to #askthecommunity in Slack, find a useful discussion with lots of replies, screenshot it, hyperlink the image and button to the Slack thread.
7. **Ad hoc announcement section** — only when needed: the Uppys, doors opening, Accelerator announcements, mentor call-outs.

## Future direction (from the handover)

Work in more community wins and insights without making it long again: promotions, new jobs, Up Club anniversaries, and invaluable insights from Huddle Ups and conversations.
