# Up Club — draft OKRs (2026)

Source: Google Doc "Draft KRs for Up Club," pulled from Drive 2026-07-22. Still marked draft in
the source — several KRs have open questions the doc itself hasn't answered yet.

## Objective 1: Grow Up Club membership

**KR 1 — 100 members join from the Jan cohort.** Cohort launch is the primary mechanism for
member growth.

**KR 2 — Churn under 75.** Based on ~25/month. Memberspace originally reported ~40/month churn,
but Memberspace was found to be over-reporting members by ~25%, so the goal was reduced to 25/month.

**KR 3 — Set the new cohort up for success (keep new joiners engaged).** Open question in the
source doc: what metrics actually track this? Candidates listed: % joining the PD workshop; % who
logged into Slack/Memberspace by a set date; 40% attending an event (PD, Up Talk, or Huddle Up) —
though April's actual was only 20%; whether mentor-matched.

## KR group: a best-in-class events programme (keep existing members engaged)
Each measured by attendance (exciting enough to show up) + satisfaction (good enough to leave
positive feedback).

**KR 4 — Deliver an outstanding Up Talk programme.** 50% weighted on attendance (target
threshold not yet set in source); 50% weighted on feedback — target 5/5 events with an average
score of 4.5+.

**KR 5 — Huddle Ups delivered with target attendance.** Target count and attendance % not yet set
in the source doc.

**KR 6 — Deliver outstanding IRL events.** Source doc flags an open question: are there IRL events
this quarter beyond the PD workshop?

## Open in the source doc — tracking gaps
The doc itself asks: where do we track attendance stats for Up Talks, attendance stats for Huddle
Ups, and feedback scores for both? Not resolved as of this pull.
